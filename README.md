# Netflix Customer Churn and Engagement Analysis

## Project Overview
This project explores Netflix customer churn, subscription behaviour, viewing engagement, customer preferences, and subscription revenue using **Microsoft Excel**.

The workbook contains a 5,000-record customer dataset, pivot-table analysis, and dashboard worksheets. It is designed to turn raw customer data into meaningful insights that can support customer-retention and engagement decisions.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel formulas and data summarisation
- Interactive dashboard reporting

## Dataset Description
The main dataset contains **5,000 customer records** and the following fields:

| Column | Description |
|---|---|
| customer_id | Unique customer identifier |
| age | Customer age |
| gender | Customer gender |
| subscription_type | Basic, Standard, or Premium subscription |
| watch_hours | Total viewing hours |
| last_login_days | Days since the customer's last login |
| region | Customer region |
| device | Device used to access Netflix |
| monthly_fee | Monthly subscription fee |
| churned | Churn status (1 = churned, 0 = not churned) |
| payment_method | Customer payment method |
| number_of_profiles | Number of profiles in the account |
| avg_watch_time_per_day | Average daily watch time |
| favorite_genre | Customer's favourite content genre |

## Workbook Contents
The Excel workbook is organised into raw data, pivot analysis, and dashboard worksheets:

- **netflic churn and engagement** – Main customer dataset.
- **1st pivot** – Customer count, churn, retention, and subscription revenue analysis.
- **1st page dashboard** – Customer churn and retention overview.
- **2nd pivot** – Regional and demographic churn analysis.
- **2nd page dashboard** – Customer churn analysis.
- **3rd pivot** – Subscription type, genre, payment, and customer preference analysis.
- **3rd page dashboard** – Customer preference and payment analysis.
- **4th pivot** – Genre-wise subscription revenue analysis.
- **4th page dashboard** – Further customer engagement and revenue analysis.
- **Sheet1** – Additional copy of the customer dataset.

*Worksheet names above follow the workbook. Dashboard topics and chart contents can be explored in the Excel file.*

## Key Analysis Areas
The project investigates questions such as:

1. What is the total number of customers?
2. How many customers have churned and not churned?
3. What is the overall customer churn rate?
4. What is the customer retention rate?
5. Which region has the highest customer churn rate?
6. Which age group and gender have the highest churn?
7. Which subscription type has the highest number of viewers for each genre?
8. Which genre generates the highest monthly subscription revenue?
9. How do customers' payment methods and subscription preferences vary?
10. How does customer viewing activity relate to churn?

## Project Workflow
1. Loaded and reviewed the customer dataset in Microsoft Excel.
2. Explored the available customer, subscription, payment, and viewing fields.
3. Used Pivot Tables to summarise customer behaviour and business metrics.
4. Analysed churn, retention, revenue, regional patterns, and viewing preferences.
5. Created dashboard worksheets with charts and key metrics.
6. Organised the workbook to present the analysis in a visual and understandable format.
